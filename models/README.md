# models/

Optimized 3D model files (`.glb`) go here, one per anatomy layer (skeleton, organs, muscles, arteries, veins,
nerves, lymphatics). Raw source downloads stay in `work/` (gitignored).

Before adding a file: read docs/PLAN_3D.md §Licensing, add `models/LICENSE` (CC BY-SA 4.0 text), and update
`CREDITS.md`.
